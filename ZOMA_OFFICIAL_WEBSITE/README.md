# ZOMA / OFFICIAL WEBSITE

遅電ゾマの公式サイト・スタータープロジェクトです。

## 起動方法（Mac）

1. このフォルダをVS Codeで開く
2. `index.html` をブラウザで開く
3. おすすめ：VS Code拡張機能「Live Server」を入れ、`index.html` を右クリック → **Open with Live Server**

## ファイル構成

- `index.html` : ページの構造・文章
- `style.css` : デザイン・レスポンシブ対応
- `script.js` : ナビゲーション・スクロール進捗表示

## 最初に差し替えるところ

- `index.html` の `YOUR KEY VISUAL` と `CHARACTER VISUAL` を、立ち絵・メインビジュアルに差し替える
- IRIAMとYouTubeのリンクを本人の公開URLに差し替える
- お問い合わせ先・事務所表記など、公開可能な情報を確認して追記する
- 実績・ギャラリー画像を追加する

## 公開前チェック

- スマートフォンとPCの両方で表示確認
- 外部リンクの確認
- 画像の権利・クレジット確認
- 事務所の表記・DM窓口の運用確認
- プライバシー・問い合わせ導線の確認
